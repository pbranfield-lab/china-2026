## Where this stands

**The "Maisie's zine" re-skin shipped at `SITE_VERSION` 3.0.0**, replacing the
dark cloisonné skin after Paul said the site still wasn't interesting to an
11-year-old. It was research-driven: NN/g's teen-UX findings plus the design
language of The Week Junior / Nat Geo Kids / DOGO News (bright and scannable
but never childish; sticker/badge graphics; big type; the peer voice front and
centre). The skin flips dark→bright: rice-paper ground, vermilion/gold/jade/
porcelain accents, thick ink outlines with hard offset shadows (lianhuanhua
comic register), tilted sticker cards, washi-tape polaroid thumbs, Lilita One
display type. Only `styles.css`, the five font links, `check.mjs`'s token
list, `SITE_VERSION` and `CLAUDE.md` changed — **zero JS/markup behaviour
changes**. `node tools/check.mjs` passes all 13 checks.

## Recommended next (research says it's the biggest win)

Every source agreed the #1 engagement feature for this age group is **doing,
not reading**: quizzes and polls (DOGO News, Newsround). A per-trip quiz built
client-side from the existing `FACTS` data ("guess the number" multiple
choice) would be cheap, factually safe, and fits `story.html` under the facts
grid. Not started — propose it to Paul before building.

## Closing out a session

1. Rewrite this file: current state, what's next, open decisions. **Keep it
   under ~5 KB.** Don't duplicate `CLAUDE.md`, `docs/authoring.md` or memory —
   architecture and gotchas belong in `CLAUDE.md`, content/photo workflow in
   `authoring.md`, finished-work narrative in git history.
2. `git mv docs/HANDOFF-<old>.md docs/HANDOFF-YYYY-MM-DD-HHMM.md` (pointers in
   `README.md` and `CLAUDE.md` say "newest", so they don't need touching).
3. Update `CLAUDE.md` if the *architecture* changed.
4. Bump `SITE_VERSION` in `assets/data.js` if content or behaviour changed.
5. Commit and push — pushing `master` publishes. Check `git remote -v` says
   `china-2026` first.
