## Closing out a session

1. Rewrite this file: current state, what's next, open decisions. **Keep it
   under ~5 KB.** Don't duplicate `CLAUDE.md`, `docs/authoring.md` or memory.
2. `git mv docs/HANDOFF-<old>.md docs/HANDOFF-YYYY-MM-DD-HHMM.md`.
3. Update `CLAUDE.md` if the *architecture* changed.
4. Bump `SITE_VERSION` in `assets/data.js` if content or behaviour changed —
   and re-stamp the `?v=` asset links to match.
5. Commit and push — pushing `master` publishes. Check `git remote -v` says
   `china-2026` first.
